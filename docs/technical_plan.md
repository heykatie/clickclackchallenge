V1 Scope

- Landscape iPad.
- 30 or 60 seconds, chosen by operator.
- Natural sentences made mostly from common words.
- Correct-WPM scoring.
- Accuracy displayed but not used for ranking.
- Minimum accuracy threshold to prevent button mashing; exact threshold can be tested.
- Any nickname.
- Top-five leaderboard.
- New event can start fresh or continue a previous leaderboard.
- Next Player resets without page refresh.
- Fully usable offline after installation.
- No accounts, backend, cloud sync, storefront, or manual clear button yet.
